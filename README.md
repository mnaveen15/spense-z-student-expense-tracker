# Spense-Z — Student Expense Tracker

## Project Type
JavaScript Internship Mini Project

## Project Description
Spense-Z is a simple student expense tracker built using HTML, CSS and JavaScript. It allows students to add expenses, view spending history, filter expenses by category, calculate total and average spending, and find affordable expenses.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## JavaScript Concepts Demonstrated
- Variables and constants
- Data types and type conversion
- if...else
- switch
- for loop
- Functions
- Arrow functions
- Arrays and objects
- forEach()
- filter()
- map()
- DOM manipulation
- Event handling
- Basic input validation

## How to Run
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a web browser.
3. Add expenses and test the analytics/filter features.

## Main Features
1. Add a new expense.
2. Validate expense name and amount.
3. Display expense history.
4. Filter expenses by category.
5. Calculate total spending.
6. Calculate average spending.
7. Show expenses under ₹200.
8. Delete individual expenses.
9. Clear all expenses.
10. Generate a formatted report using `map()`.

## Internship Relevance
The project applies the JavaScript concepts covered in the internship assignments and turns them into a practical browser-based application.
